简书配置指南 ​

通过 Cookie 授权发布到简书。图片默认上传到简书，默认使用 Markdown 发布。

一、准备 ​

  1. 在浏览器登录简书。
  2. 无需 API Token，只用 Cookie。

二、配置 ​

字段填什么
平台首页默认 https://www.jianshu.com，一般不改
API 地址默认简书 API 地址，一般不改
Cookie点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴
预览规则查看文章链接模板，默认 /p/[postid]
发布格式默认 Markdown
笔记本发布目标笔记本（如「随笔」）
图床默认「当前平台」，图片随文章上传到简书

三、验证与发布 ​

  1. 点「1 去登录」→ 登录简书 → 关闭窗口 → 点「2 自动读取 Cookie」→ 验证。
  2. 快速发布 → 选简书 → 发布。

常见问题 ​

  • Cookie 验证失败：确认浏览器已登录简书并能打开创作中心，重新读取 Cookie。
  • 图片图床：默认「当前平台」即可，图片随文章上传到简书。
  • 不能修改所属笔记本：简书平台限制，已发布文档暂不支持直接编辑笔记本。需要移动时删除原文后重新选择笔记本发布。
