# 发布设置

发布设置是插件的「通用设置」入口，分为**发布设置**与**偏好设置**两类。

## 入口

V1（SPA）：插件菜单「设置」→ `/#/setting`。偏好设置在 `/#/setting/general`（`GeneralSetting`，内含「偏好设置」表单）。

## 发布设置

- **平台账号**：新增 / 删除 / 编辑各平台配置，验证连通性。
- **图床**：图床（PicGo）相关设置。
- **AI**：AI 相关配置（体验码、模型、代理等）。

## 偏好设置

偏好设置是一组影响发布行为的开关与选项，常见项：

- **去除标题编号**（`fixTitle`）：发布时去掉 Markdown 标题里的编号。
- **不更新原始标题**（`keepTitle`）：保持思源原文标题不被平台化处理覆盖。
- **去除正文 H1** / **去除挂件 HTML**。
- **菜单显示开关**：文档快捷菜单、极速发布、常规发布、批量分发、AI、扩展、文章管理菜单是否显示。
- **忽略块引用**（`ignoreBlockRef`）：发布时忽略文中块引用。
- **允许修改别名**（`allowChangeSlug`）：允许修改文章别名（slug）；开启需自行保证唯一性，否则可能发布失败。
- **使用新版 UI（实验性）**（`useV2UI`）：开启后使用全新的 V2 界面，重启后生效。

### 发布源笔记本

- 位置：偏好设置中的「**发布源笔记本**」多选。
- 用途：限定**允许发布**的笔记本（按笔记本 `id`）。选中后仅能发布这些笔记本内的文档；**空 = 不限制**（向后兼容）。
- 作用：
  - **列表**：文章管理页 `ArticleManageList` 顶部多选，数据按 `b.box IN (...)` 过滤；变更会持久化到该偏好并刷新。
  - **发布硬校验**：所有发布入口在 `usePublish.doSinglePublish` 开头校验源文档笔记本，越权（不在授权集合）抛清晰错误；未配置时零回退。
- 用途场景：笔记过多时收敛「文章管理」列表；隔离公开 / 非公开内容（未授权笔记本的文档不可发布）。
- 系统 / 用户指南笔记本会被自动排除在可选集合之外。
