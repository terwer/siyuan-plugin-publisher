# 知乎配置指南

通过 **Cookie 授权**发布到知乎专栏。图片默认上传到知乎。

## 一、准备

1. 在浏览器登录知乎。
2. 记下自己的知乎**用户名**——打开个人主页，看地址栏 `zhihu.com/people/<用户名>`，斜杠后面那一段就是。

   ::: tip 用户名填错的后果
   填错就读不到专栏列表。验证这一步本质是**获取专栏**，用户名必须正确。
   :::

3. 无需 API Token，只用 Cookie。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://zhuanlan.zhihu.com`，一般不改 |
| API 地址 | 默认知乎专栏 API，一般不改 |
| 用户名 | 知乎用户名（个人主页地址里那一段），必须填对 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/p/[postid]` |
| 发布格式 | **必须选 HTML**，知乎目前只接受 HTML 模式 |
| 专栏 | 发布目标专栏；验证通过后从列表选择 |
| 图床 | 默认「当前平台」，图片随文章上传到知乎 |

::: warning 发布格式必须是 HTML
知乎目前**只能选择 HTML 模式**发布。选 Markdown 会出现发布异常。CSDN 同理。
:::

## 三、验证与发布

1. 点「1 去登录」→ 登录知乎 → **关闭登录窗口** → 点「2 自动读取 Cookie」。
2. 填好用户名，点「验证」→ 通过后会列出你的专栏，选择要发布到的那个并保存。
3. 快速发布 → 选知乎 → 发布。

::: tip 没有专栏也能用
不设置专栏不影响发布，只是文章不会被收录到专栏里。之后可以随时回来修改。
:::

## 常见问题

### 为什么不能改所属专栏

知乎平台限制，已发布文档暂不支持编辑专栏。取消或删除原文后，重新选择专栏发布。

### 读取不到专栏

1. 确认「用户名」填的是知乎用户名（个人主页地址里那一段），不是昵称。
2. 确认已读取 Cookie。
3. 再点验证。验证通过后专栏列表才会出现，选中后保存。

### 验证通过但无法发布

多半是**账号不一致**造成的。典型情况：手机用微信登录、电脑用手机号登录，两者不是同一个账号；再用手机知乎扫码登录，会让账号处于**未绑定**状态。

请确认登录用的是同一个账号。如果仍然不行，可以重置配置：

1. 卸载插件后重新安装；
2. 或删除 `[工作空间]/data/storage/syp/sy-p-plus-cfg.json`，然后重新添加并配置该平台。

::: warning 重置会清掉全部平台配置
删除配置文件会丢失**所有**平台账号配置，不只是知乎。操作前请先备份该文件，并关闭思源后再操作。
:::

### Cookie 验证失败

确认浏览器已登录知乎、账号能打开创作中心，然后重新读取 Cookie。Cookie 会过期，过期后按上面的流程重新授权即可。

### 报错「您当前请求存在异常，暂时限制本次访问」

知乎已限制在 Electron 内登录，只能复制 Cookie。请升级到最新版插件，然后删除该平台账号重新导入。

### 图片图床

默认「当前平台」即可。知乎不支持外链图片，必须用它自己的图片服务。
