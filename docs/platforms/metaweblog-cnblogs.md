# 博客园配置指南

> TODO：待替换真实帮助文档链接（当前 helpUrl 指向的短链需用户确认）。

博客园通过 **MetaWeblog XML-RPC** 发布。

## 一、准备

1. 一个博客园账号。
2. 一个 **API Token**（不是登录密码！）。

## 二、获取 API Token

1. 登录博客园后台 → 设置 → 开放 API（或「开放接口」）。
2. 生成并复制 Token。

## 三、在插件里配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 你的博客首页，如 `https://www.cnblogs.com/你的用户名` |
| API 地址 | `https://rpc.cnblogs.com/metaweblog/你的博客名` |
| 用户名 | 博客园登录用户名 |
| 鉴权 Token | 上面生成的 **API Token**（不是登录密码） |
| 预览规则 | 查看文章链接模板，默认 `/[userid]/p/[postid].html` |
| 发布格式 | 默认 Markdown |
| 图床 | 默认「当前平台」（博客园内置）；需要时可选「PicGo 强烈推荐」 |

## 四、验证与发布

1. 点「验证并保存」，通过后账号状态变「运行中」。
2. 快速发布 → 选博客园 → 发布。

## 五、选择发布类型与草稿

2.4.0 修复了发布类型和草稿选项不生效的问题：所选内容类型会正确应用，草稿不会被直接公开发布。

- **发布类型**：在详细发布页的「文章分类」中选择 `[发布为文章]`、`[发布为日记]` 或 `[发布为新闻]`，发布到对应类型。
- **发布至博客园首页**：`[发布至博客园首页]` 仅适用于随笔，请勿与文章、日记或新闻类型同时选择。
- **保存草稿**：在「文章状态」选择「草稿」后发布或更新。需要公开时，再将状态改为「发布」并更新文章。

## 常见问题

- **提示「用户名或密码错误」**：确认用的是 API Token 而非登录密码。
- **图片上传失败**：默认「当前平台」即可（博客园内置）；需要时可选「PicGo 强烈推荐」并先在设置里配置好 PicGo。
- **发布到了随笔而不是文章**：请升级至 2.4.0，并在详细发布页的「文章分类」中选择所需发布类型。`[发布至博客园首页]` 只适用于随笔，不能与文章/日记/新闻同时选择。
- **选了草稿却直接发布**：发布页「文章状态」选择「草稿」会存为草稿，只有选择「发布」才会公开。
