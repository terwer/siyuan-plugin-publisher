# CSDN 配置指南

通过 **Cookie 授权**发布到 CSDN。图片默认上传到 CSDN。

## 一、准备

1. 在浏览器登录 CSDN 创作中心。
2. 无需 API Token，只用 Cookie。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://blog.csdn.net`，一般不改 |
| API 地址 | 默认 `https://bizapi.csdn.net`，一般不改 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/[userid]/article/details/[postid]` |
| 发布格式 | **必须选 HTML**，CSDN 目前只接受 HTML 模式 |
| 标签 | **必填**，这是 CSDN 平台规定，标签不能为空 |
| 图床 | 默认「当前平台」，图片随文章上传到 CSDN |

::: warning 发布格式与标签
- 发布格式选 **HTML**，选 Markdown 会出现发布异常（知乎同理）。
- 标签**不能为空**，需在发布前填好。
:::

## 三、验证与发布

1. 点「1 去登录」→ 登录 CSDN 创作中心 → **关闭登录窗口** → 点「2 自动读取 Cookie」。
2. 点「验证」→ 通过后保存。
3. 快速发布 → 选 CSDN → 发布。

## 常见问题

### 过一段时间提示无法授权、需要登录

这是 Cookie 过期。有一个办法可以解决：

1. 安装「网页视图」插件，在思源内打开 CSDN 首页并**退出登录**；
2. 回到插件配置页，重新授权。

::: tip 必须在思源的网页视图里退出
在外部浏览器退出登录不会同步，所以这一步要放在思源的网页视图里做。
:::

### 发布时报标签为空

CSDN 强制要求标签，发布前请先填好标签再提交。

### Cookie 验证失败

确认浏览器已登录 CSDN 创作中心，重新读取 Cookie。

### 图片图床

默认「当前平台」即可，无需额外配置 PicGo。
