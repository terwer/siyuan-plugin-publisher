# Jvue 配置指南

通过 **MetaWeblog XML-RPC** 协议把思源笔记发布到 **Jvue** 博客。

## 一、准备

1. 一个可访问的 **Jvue** 博客站点，并开启 MetaWeblog 接口。
2. 站点的 **MetaWeblog API 端点地址**（Jvue 需显式填写，不由首页推导）。
3. Jvue 后台的**登录用户名与登录密码**（MetaWeblog 按账号密码鉴权，不使用 Token）。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 博客首页 | 你的 Jvue 博客首页地址，如 `https://blog.example.com` |
| API 地址 | 站点的 MetaWeblog 端点地址（需手动填写，不由首页推导） |
| 用户名 | Jvue 后台的登录用户名 |
| 密码 | Jvue 后台的登录密码 |
| 查看文章链接 | 固定 `/post/[postid].html`，不支持修改 |
| 发布格式 | 正文提交格式，默认 Markdown，保持默认即可 |
| 图床 | 按需选择「当前平台」「PicGo 强烈推荐」或「不使用」 |

> Jvue 通过 MetaWeblog 发布时不暴露分类目录选择，因此配置页**没有「发布目录」行**。

## 三、验证与发布

1. 点「验证」→ 站点连通性与账号校验通过 → 保持「配置已保存并验证通过」。
2. 快速发布 → 选 Jvue → 发布。文章提交到站点。
3. 「查看文章」按 `/post/[postid].html` 打开。

## 常见问题

- **验证失败或提示账号错误**：确认用户名是后台登录用户名、密码是登录密码（不使用 Token）；再确认 API 地址是站点真正提供 MetaWeblog 的端点。
- **API 地址要不要手动填**：要。Jvue 的 API 地址需要手动填入站点提供 XML-RPC 的接口地址。
- **为什么没有「发布目录」**：该协议发布时不暴露分类目录选择，文章直接进入站点。
- **查看链接能改吗**：不能，固定为 `/post/[postid].html`。
- **图片要怎么发布**：按需选择图床。「当前平台」随文章提交到站点；「PicGo 强烈推荐」先在上层设置里配置好 PicGo；「不使用」则按原图地址引用。
- **更新与删除**：点「更新」会覆盖站点上的同一篇文章；「删除」会移除该文章。
