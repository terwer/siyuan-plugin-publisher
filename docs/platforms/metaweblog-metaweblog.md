# Metaweblog 通用配置指南

通过 **MetaWeblog XML-RPC** 协议，把思源笔记发布到**任何实现了该协议、但插件尚未单独适配**的博客系统。

## 一、准备

1. 一个可访问的博客站点，且该站点**提供 MetaWeblog / XML-RPC 远程发布接口**（不是所有博客系统默认开启，需按站点的官方文档确认端点路径）。
2. 该站点后台的**登录用户名与登录密码**（MetaWeblog 按账号密码鉴权，不使用 Token）。若站点要求独立的应用密码/远程发布密码，请准备该密码。
3. 你需要**自己确知**两件事，因为通用入口不会替你推断：
   - 该站点的 **XML-RPC 端点地址**（即「API 地址」）；
   - 该站点**文章地址的形态**（即「查看文章链接」模板）。

## 二、与专用入口的区别

| | 专用入口（如博客园 / Typecho / Jvue） | 本入口（Metaweblog 通用） |
|---|---|---|
| API 地址 | 按各自约定预设或自动推导 | **需要你手动填写** |
| 查看文章链接 | 预设为该站的实际形态 | **默认留空，需要你填写** |
| 适用对象 | 已单独适配的博客系统 | 尚未单独适配的任意 MetaWeblog 博客 |

因此，若你的博客已有专用入口，**优先用专用入口**；本入口是兜底方案。

## 三、配置

| 字段 | 填什么 |
|------|--------|
| 博客首页 | 你的博客首页地址，如 `https://blog.example.com` |
| API 地址 | 该博客的 MetaWeblog XML-RPC 端点，常见形态为 `/xmlrpc.php` 或 `/action/xmlrpc`，**以站点实际为准** |
| 用户名 | 该博客后台的登录用户名 |
| 密码 | 该博客后台的登录密码（或站点要求的应用密码） |
| 查看文章链接 | 文章地址模板，`[postid]` 会被替换为文章 ID，如 `/?p=[postid]`、`/archives/[postid]` |
| 发布格式 | 正文提交格式，默认 HTML，保持默认即可 |
| 图床 | 按需选择「当前平台」「PicGo 强烈推荐」或「不使用」 |

> 通用入口通过 MetaWeblog 发布时不暴露分类目录选择，因此配置页**没有「发布目录」行**。

## 四、验证与发布

1. 点「验证」→ 站点连通性与账号校验通过 → 保持「配置已保存并验证通过」。
2. 快速发布 → 选「Metaweblog 通用」→ 发布。文章提交到该站点。
3. 点「查看文章」验证链接可打开；打不开时说明「查看文章链接」模板与本站实际形态不符，回到配置页修正。

## 五、常见问题

**Q：API 地址填什么？**
A：填该博客的 MetaWeblog XML-RPC 端点。不同博客系统路径不同，可在博客系统官方文档里确认远程发布端点。

**Q：验证失败或提示账号错误？**
A：确认用户名是后台登录用户名、密码是登录密码（该协议不使用 Token）；再确认 API 地址是可访问的 XML-RPC 端点。若站点要求独立的应用密码，请改用应用密码。

**Q：为什么没有「发布目录」？**
A：通用入口通过 MetaWeblog 发布时不暴露分类目录选择，文章直接进入站点，因此配置页不提供该行。

**Q：查看文章链接打不开？**
A：查看链接按「查看文章链接」模板拼出，而该模板**默认留空**。请按本站文章地址的实际形态填写，例如 `/?p=[postid]` 或 `/index.php/archives/[postid]`。
