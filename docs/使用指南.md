# 使用指南

本插件用于把思源笔记发布到各类平台（博客、论坛、知识社区、图床等），支持单个、快速、批量等多种发布方式，并提供统一的文章管理与内容隔离能力。

## 功能总览

| 模块 | 说明 | 文档 |
|---|---|---|
| 文章管理 | 统一列出/筛选/操作已发布与未发布文章；支持按发布源笔记本收敛范围 | [文章管理](文章管理.md) |
| 常规发布 | 发布单篇文档的完整流程 | [常规发布](常规发布.md) |
| 极速发布 | 快速发布当前/指定文档 | [极速发布](极速发布.md) |
| 批量分发 | 一篇文档同时分发到多个平台 | [批量分发](批量分发.md) |
| 发布设置 | 平台账号、图床、AI 与偏好设置 | [发布设置](发布设置.md) |
| 分类体系 | 平台分类/专栏的选取方式说明 | [分类体系](分类体系.md) |
| 人工智能 | AI 相关能力（体验码、模型配置、AI 菜单等） | [人工智能](人工智能.md) |

## 快速开始

1. 在「发布设置」中「新增平台账号」并验证连通性。
2. 按需在「偏好设置」中调整发布行为；如需隔离公开/非公开内容，可设置「发布源笔记本」。
3. 进入「文章管理」选择笔记本范围，对目标文档执行常规/快速/批量发布。

## 界面版本说明

- **V1**：经典 SPA（`dist/`，含 `index.html`，路由可用）。
- **V2**：全新原生 DOM 界面（`dist-v2/`），发布面板入口为头部**房子图标**（设置齿轮左侧）与设置；V2 为完整替代品，管理动作全部原生实现。
