# 文章管理

文章管理是插件的统一管理入口，用于集中列出、筛选和操作已发布 / 未发布的文章。笔记过多时，可通过**发布源笔记本**限定只管理与某几个笔记本相关的文档，隔离「公开内容」与「非公开内容」。

## 入口

| 环境 | 入口 |
|---|---|
| V1（SPA） | 插件菜单「文章管理」→ `/#/`（`Admin` 页） |
| V2（原生 DOM） | 发布面板头部 **房子图标**（位于「设置齿轮」左侧）→「管理」视图 |

> V1 与 V2 共用同一套列表 UI 与数据层（共用组件 `ArticleManageList.vue` + `useArticleManage.ts`），V2 不再另起皮肤。

## 列表与筛选

顶部过滤条提供以下能力：

- **发布源笔记本**：多选，按笔记本收敛可管理的文档。选定后仅列出这些笔记本内的文档；选择会**持久化**到偏好设置并刷新列表；**空 = 不限制**（向后兼容，行为与之前完全一致）。
- **搜索**：按关键字过滤文档标题/内容，回车或点击「搜索」触发。
- **已发布**：勾选后仅显示已发布的文档。
- **分页**：底部分页，切换页码重新加载。

## 列表列说明

- **标题列**：文档标题；标题右上角数字徽标表示已发布到的平台数量。
- **展开行**：点击行首展开，查看：
  - ID、发布时间、完整标题
  - 标签（`mt_keywords`）
  - 摘要
  - 平台：列出该文档已发布到的平台（带各平台图标）；点击任一平台可对该文档单独执行「发布到该平台」。
- **操作列**：
  - **闪发 / 单发**：进入该文档的发布流程。
  - **批发**：将该文档批量发布到全部「已启用 + 已授权」平台。
  - **查看**（仅已分享文档显示）：打开该文章的预览链接。
  - **图床**：打开图床工具。

> 各能力能否显示取决于对应插件是否安装（如 siyuan-blog、siyuan-plugin-picgo）。V2 下上述动作均为**原生实现**，不会回退到 V1。

## 发布源笔记本（重要）

- 用途：笔记过多时避免「文章管理」列出全部笔记本的所有文档；同时限制**只能发布**选中笔记本内的文档，隔离公开/非公开内容。
- 作用范围：**列表数据层过滤** + **发布时硬校验**。
  - 列表：`ArticleManageList` 顶部多选，数据在底层按 `b.box IN (...)` 过滤。
  - 发布：`usePublish.doSinglePublish` 开头校验源文档笔记本，越权（未在授权集合内）抛清晰错误。
- 配置位置：V1「偏好设置」/ V2「偏好设置」里的 **发布源笔记本** 多选。
- 空值语义：**空 = 不限制**（向后兼容）。
- 挂件一致性：挂件模式（当前文档子文档树）同样应用笔记本过滤，与浏览器模式行为一致，不留脏路径。

## 发布硬校验

所有发布入口（单发 / 批发 / 快发 / V2 快发）都汇入 `usePublish.doSinglePublish`。当配置了 `publishSourceNotebooks`（非空）时：

- 取源文档的 `blocks.box`（所属笔记本 id）。
- `box` 在授权集合内 → 放行；不在 → 抛出可读错误（如「该文档所属笔记本不在发布的授权笔记本集合内，无法发布」）。
- `box` 取不到 → 视为未限定，放行并记录日志（避免误拦）。
