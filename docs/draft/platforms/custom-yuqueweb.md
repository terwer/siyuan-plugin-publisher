# 语雀网页版配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到语雀，**无需专业会员**，适合已在浏览器登录语雀的账号。

## 一、准备

1. 在浏览器登录语雀（网页版）。
2. 无需 API Token。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| Cookie | 自动从浏览器读取，也可手动粘贴 |
| 知识库 | 验证后选择可写知识库 |
| 预览地址 | 默认 `/{login}/{bookSlug}/{slug}`，一般不改 |
| 图床 | 内置图片链路，默认 Bundled |

## 三、验证与发布

1. 点「去登录」→ 自动打开语雀登录页 → 登录 → 关闭窗口（关闭时保存 Cookie）。
2. 点「自动读取 Cookie」→ 验证。
3. 快速发布 → 选语雀网页版 → 发布。

## 常见问题

- **Cookie 读取失败**：确认浏览器已登录语雀，点「自动读取」重试。
- **和 API 模式的区别**：Cookie 模式无需会员，但依赖浏览器登录态；API 模式更稳但受会员限制。
- **发布失败但配置能验证**：检查知识库写入权限和 Cookie 是否过期。
