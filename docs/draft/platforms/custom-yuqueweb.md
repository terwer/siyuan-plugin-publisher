# 语雀网页版配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到语雀，**无需专业会员**，使用浏览器登录态即可发布。

## 一、准备

1. 一个可登录的语雀账号（网页版）。
2. 无需 API Token。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 语雀站点地址，固定为 `https://www.yuque.com`，通常无需修改 |
| API地址 | 语雀接口地址，与站点地址一致，通常无需修改 |
| Cookie | 点「去登录」登录语雀 → 关闭登录窗口（关闭时保存登录态）→ 点「自动读取 Cookie」写入本账号；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/{login}/{bookSlug}/{slug}`，支持 `{login}`、`{bookSlug}`、`{slug}` 占位符，一般不改 |
| 发布格式 | 语雀网页版按 Markdown 提交正文，保持默认的 Markdown |
| 知识库 | 验证通过后选择要发布到的知识库（读取当前登录账号可写的知识库列表） |
| 图床服务 | 默认「当前平台」，图片作为语雀附件上传；也可选「不使用」按原图地址引用（需公网可访问）。语雀网页版不支持 PicGo |

## 三、验证与发布

1. 点「去登录」→ 打开语雀登录页 → 登录成功 → **关闭登录窗口**（关闭时保存 Cookie）。
2. 点「自动读取 Cookie」→ 读取到登录态后点「验证」→ 账号状态变为已授权。
3. 选择知识库后保存配置。
4. 快速发布 → 选语雀网页版 → 发布。发布后可在「查看文章」打开文章。

## 常见问题

- **Cookie 读取失败**：确认已登录语雀，关闭登录窗口后点「自动读取 Cookie」重新获取。
- **和 API 模式有什么区别**：Cookie 模式无需专业会员，但依赖浏览器登录状态；API 模式更稳但受语雀会员策略限制。
- **发布失败但配置能验证**：检查目标知识库写入权限和 Cookie 是否过期，再重新读取 Cookie 后验证。
- **文章发布到哪里**：发布到所选知识库下；未选择知识库时不会发布，验证通过后会读取可写知识库列表。
