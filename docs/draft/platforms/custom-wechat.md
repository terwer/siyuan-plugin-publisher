# 微信公众号配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过登录公众号后台的 **Cookie** 发布到微信公众号。以 HTML 内容发布，图片默认上传到公众号素材库。

## 一、准备

1. 用**公众号管理员**的微信扫码登录公众号后台 `https://mp.weixin.qq.com`。
2. 保持该浏览器会话登录状态（后续读取 Cookie 用）。
3. 无需 AppID/AppSecret（通过浏览器 Cookie 发布）。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://mp.weixin.qq.com`，一般不改 |
| API 地址 | 默认公众号后台接口地址，一般不改 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 公众号文章编辑页 URL 模板，一般不改 |
| 发布格式 | 默认 HTML |
| 图床 | 默认「当前平台」（公众号素材库） |

## 三、验证与发布

1. 点「1 去登录」→ 用公众号管理员微信扫码登录 mp.weixin.qq.com → 关闭窗口 → 点「2 自动读取 Cookie」→ 验证。
2. 快速发布 → 选公众号 → 发布。

## 常见问题

- **Cookie 验证失败**：确认已用公众号管理员账号登录 mp.weixin.qq.com（微信扫码登录），重新读取 Cookie。
- **图片图床**：默认「当前平台」即可。公众号通过素材库接口上传图片，不依赖本机 PicGo 服务。
- **发布成功但内容为空**：公众号以 HTML 内容发布。若文档为纯 Markdown，请确认文档能正确渲染为 HTML 后再发布。
