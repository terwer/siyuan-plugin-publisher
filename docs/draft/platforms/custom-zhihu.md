# 知乎配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到知乎专栏。图片默认上传到知乎。

## 一、准备

1. 在浏览器登录知乎。
2. 记下自己的知乎用户名（个人主页地址 `zhihu.com/people/<用户名>` 里那一段）。
3. 无需 API Token。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://zhuanlan.zhihu.com`，一般不改 |
| API 地址 | 默认知乎专栏 API，一般不改 |
| 用户名 | 自己的知乎用户名；必须填对，否则读取不到专栏 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/p/[postid]` |
| 发布格式 | 默认 HTML |
| 专栏 | 选择发布目标专栏（验证通过后读取列表） |
| 图床 | 默认「当前平台」，图片随文章上传到知乎 |

## 三、验证与发布

1. 点「1 去登录」→ 登录知乎 → 关闭窗口 → 点「2 自动读取 Cookie」→ 验证。
2. 快速发布 → 选知乎 → 发布。

## 常见问题

- **为什么不能改所属专栏**：知乎平台限制，已发布文档暂不支持编辑专栏。取消/删除原文后重选专栏发布。
- **读取不到专栏**：先确认「用户名」填的是知乎用户名（个人主页地址里那一段），并已读取 Cookie，再点验证。
- **Cookie 验证失败**：确认浏览器已登录知乎、账号可访问专栏后台，重新读取 Cookie。
- **图片图床**：默认「当前平台」即可。
