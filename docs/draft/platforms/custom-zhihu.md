# 知乎配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到知乎专栏。V2 已验证完整链路（含平台内置图片）。

## 一、准备

1. 在浏览器登录知乎。
2. 无需 API Token。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://zhuanlan.zhihu.com`，一般不改 |
| API 地址 | 默认知乎专栏 API，一般不改 |
| Cookie | 登录知乎后自动读取，或手动粘贴 |
| 专栏 | 选择发布目标专栏 |
| 图床 | 已验证平台内置图片链路，默认 Bundled |

## 三、验证与发布

1. 点「去登录」→ 登录知乎 → 关闭窗口 → 「自动读取 Cookie」→ 验证。
2. 快速发布 → 选知乎 → 发布。

## 常见问题

- **为什么不能改所属专栏**：知乎平台限制，已发布文档暂不支持编辑专栏。取消/删除原文后重选专栏发布。
- **Cookie 验证失败**：确认浏览器已登录知乎、账号可访问专栏后台，重新读取 Cookie。
- **图片图床**：默认 Bundled 已验证可用。
