# 简书配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到简书。V2 已验证完整链路（含平台内置图片）。

## 一、准备

1. 在浏览器登录简书。
2. 无需 API Token，只用 Cookie。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://www.jianshu.com`，一般不改 |
| API 地址 | 默认简书 API 地址，一般不改 |
| Cookie | 登录简书后自动读取，或手动粘贴 |
| 笔记本 | 选择发布目标笔记本（如“随笔”） |
| 发布格式 | 简书 V2 默认使用 Markdown |
| 图床 | 已验证平台内置图片链路，默认 Bundled |

## 三、验证与发布

1. 点「去授权」→ 登录简书 → 关闭窗口 → 「自动读取 Cookie」→ 验证。
2. 快速发布 → 选简书 → 发布。

## 常见问题

- **Cookie 验证失败**：确认浏览器已登录简书并能打开创作中心，重新读取 Cookie。
- **图片图床**：选择“当前平台 推荐”（Bundled）。简书通过平台图床上传图片。
- **不能修改所属笔记本**：简书平台限制，已发布文档暂不支持直接编辑笔记本。需要移动时删除原文后重新选择笔记本发布。
