# 语雀 API 配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过**语雀 API Token** 发布到语雀知识库。V2 已验证完整链路。
> ⚠️ 语雀 API 发布需要**专业会员**，这是语雀平台策略，不是插件问题。免费账号请改用「语雀网页版（Cookie 模式）」。

## 一、准备

1. 语雀账号（专业会员）。
2. 一个 **API Token**。

## 二、获取 Token

语雀设置 → 访问令牌 → 生成。地址：<https://www.yuque.com/settings/tokens>

## 三、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 语雀主页，如 `https://www.yuque.com/你的用户名` |
| API 地址 | 默认语雀 v2 API，一般不改 |
| 用户名 | 与 Token 对应的语雀账号 |
| Token | 上面生成的访问令牌 |
| 知识库 | 验证通过后从下拉选择可写知识库 |
| 图床 | 语雀已验证内置图片链路，默认即可 |

## 四、验证与发布

1. 点「验证」→ 拉取知识库列表 → 选知识库 → 保存。
2. 快速发布 → 选语雀 → 发布。

## 常见问题

- **提示「权限不足」**：语雀 API 需要专业会员，免费版改用语雀网页版。
- **知识库列表为空**：确认 Token 正确、账号下有可写知识库、先点验证。
- **不能改已发布文档所属知识库**：语雀 API 平台限制，删除原绑定后重新选库发布。
