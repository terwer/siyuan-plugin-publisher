# Telegraph 配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Telegraph** 发布到 Telegra.ph 页面。Telegraph 为 **CORS 受限平台**（域名被网络环境阻断），必须填写你自己的 **CORS 代理地址** 才能正常访问，且支持 **匿名发布** 与 **登录发布** 两种模式。V2 已验证完整链路（配置、发布、更新、查看链接）。

## 一、前置说明

1. Telegra.ph 是一个网页平台，非开放 API；本插件通过其网页表单端点（`/check`、`/save`）发布。
2. **必须配置 CORS 代理**：Telegra.ph 域名在部分网络环境下无法直连，需通过你自己的 CORS 代理转发。切勿依赖共享代理（不再免费提供，且易被滥用）。
3. 支持两种发布模式，配置页通过「登录模式」切换。

## 二、匿名发布

匿名发布无需 Telegraph 账号，适合快速生成可分享的轻量文章。

1. 在配置页「登录模式」选 **匿名发布**。
2. 平台首页、API 地址保持默认（`https://telegra.ph`、`https://edit.telegra.ph`）。
3. 「新代理」填写你自己的 CORS 代理地址。
4. 点「验证」——插件自动调用 `/check` 获取 **Uuid** 与 **Hash** 并保存。
5. 验证通过后即可发布；文章为匿名，作者可自定义（默认为空）。

## 三、登录发布

登录发布将文章归入你的 Telegraph 账号。

1. 在配置页「登录模式」选 **登录发布**。
2. 从浏览器开发者工具读取以下字段并填写：
   - **Access Token**：Telegraph 账号的 token。
   - **Uuid**：`tph_uuid` 的值。
   - **Hash**：`save hash`。
3. 「新代理」填写你自己的 CORS 代理地址。
4. 点「验证」通过后即可发布。

## 四、获取 Uuid / Hash（匿名模式）

- 匿名模式下，验证（`/check`）会自动获取并保存 Uuid 与 Hash，无需手动填写。
- 若切换设备（含从 PC 到浏览器环境），需重新验证并获取新 Uuid/Hash。

## 五、字段说明

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 通常固定 `https://telegra.ph`，保持默认 |
| API 地址 | 通常固定 `https://edit.telegra.ph`，保持默认 |
| 登录模式 | 匿名发布 / 登录发布，按需切换 |
| 作者 | 显示在文章详情，可自定义，默认为空 |
| Uuid | 匿名模式验证自动获取；登录模式手动填 `tph_uuid` |
| Hash | 匿名模式验证自动获取；登录模式手动填 `save hash` |
| 预览规则 | 固定 `/[postid]`，不可修改；查看链接通过 CORS 代理访问 |
| 新代理(CORS) | 必填：你自己的 CORS 代理地址，例如 `https://cors.yourdomain.com` |

## 六、验证与发布

1. 配置页点「验证」→ 连通性测试通过（匿名自动获取 Uuid/Hash）。
2. 快速发布 → 选 Telegraph → 发布。
3. 发布后「查看文章」通过你的 CORS 代理打开 Telegra.ph 页面。

## 常见问题

- **提示「需要配置 CORS 代理地址」**：Telegraph 为 CORS 受限平台，请在「新代理」填写你自己的 CORS 代理地址。
- **提示「telegra.ph 请求错误」**：多为 CORS 代理不可用或 Uuid/Hash 失效，重新验证或更换代理。
- **切换设备后发布失败**：Telegraph 的 Uuid/Hash 与设备绑定，需重新验证获取新值。
- **支持图片上传吗**：暂不支持。Telegra.ph 不提供平台图片上传，建议配合本地或图床方案。
- **查看文章打不开**：确认你的 CORS 代理可访问，且当前网络可连到该代理。
