# CSDN 配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到 CSDN。图片默认上传到 CSDN，默认使用 Markdown 发布。

## 一、准备

1. 在浏览器登录 CSDN 创作中心。
2. 无需 API Token。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://blog.csdn.net`，一般不改 |
| API 地址 | 默认 `https://bizapi.csdn.net`，一般不改 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/[userid]/article/details/[postid]` |
| 发布格式 | 默认 Markdown |
| 图床 | 默认「当前平台」，图片随文章上传到 CSDN |

## 三、验证与发布

1. 点「1 去登录」→ 登录 CSDN 创作中心 → 关闭窗口 → 点「2 自动读取 Cookie」→ 验证。
2. 快速发布 → 选 CSDN → 发布。

## 常见问题

- **Cookie 验证失败**：确认浏览器已登录 CSDN 创作中心，重新读取 Cookie。
- **图片图床**：默认「当前平台」即可，无需额外配置 PicGo。
- **分类/标签异常**：确认创作中心能正常读取相关数据。
