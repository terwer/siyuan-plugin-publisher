# 本地系统配置指南（草稿）

> TODO：待替换真实帮助文档链接。

把文档导出为 Markdown 到本地文件系统，附带静态站点 Front Matter（YAML）。仅在桌面端（Electron）环境可用。

## 一、适用场景

- 把思源文档批量导出为 Markdown，供 Hexo / Hugo / Jekyll / VuePress / VitePress 等静态站点使用。
- 仅 Electron 桌面环境可用（需访问本机文件路径）。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 文章输出目录 | Markdown 写入位置，默认 `Downloads/syp`，支持占位符 |
| 图片目录 | 图片相对保存目录，默认 `assets` |
| YAML 类型 | 按目标站点选择 Front Matter 风格 |
| 图床 | 默认内置图片保存，图片写入媒体目录 |

## 三、发布

快速发布 → 选本地系统 → 发布，文档会导出到配置的输出目录。

## 常见问题

- **为什么只有桌面环境可用**：需要访问本机文件路径，浏览器环境不可用。
- **图片存哪**：默认在文章目录下的 `assets` 子目录。
- **YAML 类型选哪个**：按后续消费 Markdown 的静态站点框架选，普通 Markdown 用默认即可。
