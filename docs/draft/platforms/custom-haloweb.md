# Halo 网页版配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到 **Halo 2.20+**。图片默认走「当前平台」（Halo 附件库）。

## 一、准备

1. 一个 Halo 2.20+ 站点（含后台登录账号）。
2. 在浏览器登录 Halo 后台。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | Halo 博客首页完整地址，如 `https://yourhalo.com` |
| API 地址 | 通常和首页地址相同 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/archives/{slug}` |
| 发布格式 | 默认 HTML |
| 图床 | 默认「当前平台」（Halo 附件库）；不需要上传图片时可选「不使用」 |

> ⚠️ 必须先填「平台首页」完整 URL，再点登录/读取 Cookie；否则会提示 `Invalid URL`。

## 三、验证与发布

1. 点「1 去登录」→ 自动打开 Halo 登录页 → 用后台账号登录 → **关闭窗口**（关闭时保存 Cookie）。
2. 点「2 自动读取 Cookie」→ 验证 → 账号状态「运行中」。
3. 快速发布 → 选 Halo网页版 → 发布。

## 常见问题

- **提示「Invalid URL」**：先填完整站点地址，再点登录/读取 Cookie。
- **Halo 版本要求**：需 2.20 及以上。
- **验证报「接口返回异常/登录状态可能已失效」**：Cookie 过期或 Halo 重启导致会话失效，重新登录读取 Cookie。
- **图片图床**：默认「当前平台」即可；需要与思源一致的图床时可改选 PicGo。
