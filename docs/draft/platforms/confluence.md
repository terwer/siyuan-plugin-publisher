# Confluence 配置指南（草稿）

通过 **Atlassian Confluence** 发布文档。

Confluence 使用个人访问令牌（Personal Access Token, PAT）鉴权，按「空间」发布；可选择挂载到某个「父页面」下。

## 一、准备

1. 一个可访问的 Confluence 站点（如 `http://localhost:8090`）。
2. 一个可用的 **个人访问令牌（PAT）**：登录 Confluence 后访问「个人访问令牌」页面（`/plugins/personalaccesstokens/usertokens.action`）创建并复制。PAT 只在创建时展示一次，请妥善保存。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | Confluence 站点首页地址，如 `http://localhost:8090` |
| API 地址 | Confluence API 地址，修改首页后通常自动同步 |
| 鉴权令牌 | 上一步生成的个人访问令牌（PAT） |
| 父页面 ID | 可选：将页面挂载到指定父页面下；不填则为顶层页面 |
| 空间 | 选择目标空间（Space），验证后会拉取账号可访问的空间列表 |
| 图床服务 | 默认用「当前平台」（Confluence 自带附件）上传图片；也可选 PicGo 等图床方案 |

## 三、验证与发布

1. 填写平台首页、鉴权令牌，点「验证」→ 拉取空间列表 → 选择目标空间并保存。
2. 快速发布 → 选 Confluence → 发布。发布后可在「查看文章」打开页面。

## 常见问题

- **验证失败或提示「请求 Confluence API 异常」**：确认平台首页/API 地址可达、PAT 有效；通常是令牌无效或地址不可达。
- **平台端文章已手动删除后无法删除**：平台端文章不存在时，正常删除会失败，可在删除失败后点击「强制删除」仅解除本地关联（不会重新触达平台）。
- **文章发布到哪里**：发布到所选「空间」下；未选父页面时为顶层页面，否则挂载到父页面下。
- **图片怎么发布**：默认用当前平台（Confluence 自带附件）上传，图片以附件形式挂载到页面下，无需额外图床。
