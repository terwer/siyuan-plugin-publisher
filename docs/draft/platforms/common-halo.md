# Halo API 配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Halo API** 发布到 Halo 2.x 博客。V2 已验证完整链路（配置、发布、更新、删除、带图发布、查看链接）。

> **版本提示**：Halo API 平台仅支持 **Halo 2.9**。Halo 2.20+ 已调整 API 策略，本平台无法使用；请改用「Halo网页版」平台。

## 一、准备

1. 一个可访问的 Halo 2.x 博客站点。
2. 能登录该站点的 **用户名与密码**。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 首页地址 | Halo 站点首页地址，通常与 API 地址一致，如 `https://yourhalo.com` |
| API 地址 | Halo 站点 API 地址，通常与首页地址相同 |
| 用户名 | Halo 登录用户名（非令牌） |
| 密码 | Halo 登录密码，与用户名一起用于 API 认证（非令牌） |
| 预览规则 | 默认 `/archives/{slug}`；查看链接 `https://<host>/archives/<slug>`，可修改 |
| 图床 | Halo 支持内置图床，选「当前平台」：图片上传到 Halo 附件（`/upload/`） |

## 三、验证与发布

1. 点「验证」→ 拉取分类列表 → 选择文章所属分类 → 保存。
2. 快速发布 → 选 Halo29 → 发布。

## 常见问题

- **验证通过但发布失败**：确认首页/API 地址可访问（http 与 https 保持一致），用户名与密码正确，账号有发文与上传附件权限。
- **提示仅在 2.9 可用**：Halo 2.20+ 已调整 API 策略，请改用「Halo网页版」平台。
- **图片要怎么发布**：选「当前平台」图床，图片上传到 Halo 附件，文章中展示为 `/upload/<图片名>` 地址。
- **查看链接打不开**：确认预览规则（默认 `/archives/{slug}`）与文章 slug 匹配，且文章已发布为非草稿状态。
