# 哔哩哔哩配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过登录哔哩哔哩的 **Cookie** 发布到哔哩哔哩专栏（opus）。图片默认走平台上传，以 Markdown 发布。

## 一、准备

1. 在浏览器登录哔哩哔哩 `https://www.bilibili.com`（需可访问创作中心 `https://member.bilibili.com`）。
2. 保持该浏览器会话登录状态（后续读取 Cookie 用）。
3. 无需额外 Token（通过浏览器 Cookie 发布）。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://www.bilibili.com/opus`，一般不改 |
| API 地址 | 默认 `https://api.bilibili.com`，一般不改 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/[postid]`（对应专栏地址 `/opus/<id>`） |
| 发布格式 | 默认 Markdown |
| 文集 | 发布目标文集（如「远方的灯塔」）；未选择时发布为独立专栏 |
| 图床 | 默认「当前平台」（平台图片上传） |

## 三、验证与发布

1. 点「1 去登录」→ 在弹出的 B 站登录窗完成登录 → **关闭窗口**（触发 Cookie 落盘）→ 回到插件点「2 自动读取 Cookie」→ 检查其余字段 → 点「验证」。
2. 快速发布 → 选哔哩哔哩 → 发布；发布成功后点「查看文章」打开 `https://www.bilibili.com/opus/<id>`。

## 常见问题

- **Cookie 验证失败**：确认浏览器已登录哔哩哔哩且可访问创作中心（member.bilibili.com），重新读取 Cookie。
- **图片图床**：默认「当前平台」即可。哔哩哔哩使用平台图片上传，不依赖本机 PicGo 服务。
- **发布后在哪里查看**：发布成功后点「查看文章」打开专栏链接，也可在 B 站创作中心 → 专栏管理查看。
