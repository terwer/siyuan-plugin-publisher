# 掘金配置指南（草稿）

> TODO：待替换真实帮助文档链接。

通过 **Cookie 授权**发布到掘金。图片默认走掘金原生上传，默认使用 Markdown 发布。

## 一、准备

1. 在浏览器登录掘金。
2. 无需 API Token，只用 Cookie。
3. 确认能打开掘金创作中心。

## 二、配置

| 字段 | 填什么 |
|------|--------|
| 平台首页 | 默认 `https://juejin.cn`，一般不改 |
| API 地址 | 默认 `https://api.juejin.cn`，一般不改 |
| Cookie | 点「1 去登录」登录后关闭窗口，再点「2 自动读取 Cookie」；也可展开「手动编辑」直接粘贴 |
| 预览规则 | 查看文章链接模板，默认 `/post/[postid]` |
| 发布格式 | 默认 Markdown |
| 分类 | 发布目标分类（如「后端」）；未选择回退默认分类「后端」 |
| 图床 | 默认「当前平台」（掘金原生直传）；也可选「不使用」或「PicGo 强烈推荐」 |

> 标签与摘要：掘金要求带标签与摘要，未显式设置时插件回退默认标签「程序员」与默认摘要。

## 三、验证与发布

1. 点「1 去登录」→ 登录掘金 → 关闭窗口 → 点「2 自动读取 Cookie」→ 验证。
2. 快速发布 → 选掘金 → 发布。

## 常见问题

- **发布时报“必须选择一个分类/标签”或“摘要参数错误”**：掘金要求分类、标签和摘要。未显式设置时插件会用默认分类“后端”、默认标签“程序员”与默认摘要；建议在文档里显式做好设置。
- **Cookie 验证失败**：确认浏览器已登录掘金并能打开创作中心，重新读取 Cookie。
- **图片图床**：默认「当前平台」，掘金使用平台原生直传。外链图片原样保留、不转存；不需要本机 PicGo 服务，需要时可改选「PicGo 强烈推荐」。
- **文章一直“审核中”**：掘金新文章初始处于审核（audit=1），需平台放行后（audit=2）才对外可见，与上传机制无关。
