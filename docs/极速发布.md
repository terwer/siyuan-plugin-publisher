# 极速发布

极速发布用于快速把当前（或指定）文档发布到目标平台，通常提供一个精简的平台选择与一键发布入口。

## 入口

V1（SPA）：`/#/publish/quickSelect`（`QuickPublishSelectPlatform` 页）；内部 worker `/#/workers/quickPublish/:key/:id`。

## 流程

1. 选择目标平台。
2. 一键发布：调用统一的发布流程，展示发布状态与结果。

## 与文章管理的联动

- 文章管理行内「闪发」进入某文档的极速发布。
- 发布前执行「发布源笔记本」硬校验（见 `文章管理.md`）：越权文档会被拦截并给出可读错误。

> V2 的极速发布（`useV2QuickPublish`）支持按指定文档 `pageId` 发布，供文章管理逐行「闪发/单发」使用。
