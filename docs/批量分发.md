# 批量分发

批量分发用于把一篇文档**同时发布到多个平台**（批量分发/多平台一次分发）。

## 入口

V1（SPA）：`/#/publish/batchPublish`（`BatchPublish` 页）。

## 流程

1. 选择目标文档。
2. 选择要分发到的多个平台（账号），可勾选多个。
3. 一次触发，对每个平台逐个执行发布，汇总各平台结果。

## 与文章管理的联动

- 文章管理行内「批发」进入某文档的批量分发。
- V2 下「批发」为**原生批量流**（`useV2ArticleManage.publishBatchToAll`）：将该文档发布到全部「已启用 + 已授权」平台，成功/部分失败以提示/诊断反馈。
- 发布前执行「发布源笔记本」硬校验（见 `文章管理.md`）：越权文档会被拦截并给出可读错误。
