# 常规发布

常规发布是发布**单篇**文档的完整流程：选择平台、配置该次发布参数后再发布。

## 入口

V1（SPA）：`/#/publish/singlePublish`（`SinglePublish` 页）。

## 流程

1. 选择目标文档（默认带入当前文档；也可在文章管理中逐行进入某文档的常规发布）。
2. 选择目标平台（账号）。
3. 配置该次发布参数并校验连通性（`validatePublish`）。
4. 触发发布：新增或更新到平台，返回预览链接与结果（成功/失败及诊断信息）。

## 与文章管理的联动

- 文章管理行内「单发」进入某文档的常规发布：`/#/publish/singlePublish?id=<docId>`。
- 行内平台徽标点击直接进入指定平台发布：`/#/publish/singlePublish/doPublish/<platformKey>/<docId>?method=edit`。
- 发布前执行「发布源笔记本」硬校验（见 `文章管理.md`）：越权文档会被拦截并给出可读错误。
