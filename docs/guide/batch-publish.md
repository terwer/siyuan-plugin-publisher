# 批量分发

批量分发把一篇文档**一次发到多个平台**：勾好目标平台，点「开始同步」，插件逐个平台执行并汇总结果。

![批量分发](/images/shots/batch-publish.webp)

## 入口

发布面板 → **批量分发**；或在文章管理里点某篇文档的「批发」。

## 流程

1. 确认「文章标题」（可从文档自动提取）。
2. 选择**分发模式**：覆盖或合并。
3. 在平台图标区勾选要发布的平台，可多选。
4. 点「开始同步」，逐个平台执行，展示各平台结果。

## 分发模式

| 模式 | 行为 |
|---|---|
| **覆盖** | 用当前文档内容整体覆盖平台上的文章 |
| **合并** | 标签与分类和平台数据合并；标题与摘要的改动不生效 |

::: warning 关于覆盖
发布工具每次都会用思源里**最新编辑的正文**覆盖发布。因此不要在平台上直接改正文，改动会在下次发布时被覆盖。
:::

## 底部操作

| 按钮 | 说明 |
|---|---|
| 开始同步 | 对勾选的平台执行发布 |
| 批量删除 | 批量清理这些平台上的发布记录 |
| 同步修改到思源笔记 | 把本次改动写回文档 |

## 与文章管理的联动

- 文章管理的「批发」会把该文档发到**全部「已启用且已授权」**的平台。
- 发布前执行**发布源笔记本**校验：不在授权范围内的文档会被拦下。
