# 文章管理

文章管理是插件的统一管理入口：集中列出、筛选和操作已发布与未发布的文档。

笔记很多时，可以用**发布源笔记本**限定范围，把「公开内容」与「非公开内容」隔离开。

![文章管理](/images/shots/article-manage.webp)

## 入口

发布面板头部的**房子图标**（在「设置齿轮」左侧）。

## 列表与筛选

| 筛选项 | 说明 |
|---|---|
| 发布源笔记本 | 多选，只看这些笔记本里的文档；**留空 = 不限制** |
| 搜索 | 按关键字过滤标题与内容 |
| 已发布 | 勾选后只看已发布过的文档 |
| 分页 | 底部分页切换 |

## 每一行能做什么

**标题列**右上角的数字，表示这篇文档已发布到几个平台。

展开一行可以看到 ID、发布时间、标签、摘要，以及**已发布到的平台**——点任一平台图标，就能把这篇单独发到那个平台。

**操作列**：

| 按钮 | 说明 |
|---|---|
| 闪发 / 单发 | 进入这篇文档的发布流程 |
| 批发 | 一次发到全部「已启用且已授权」的平台 |
| 查看 | 打开已发布文章的链接 |
| 图床 | 打开图床工具 |

::: tip 按钮是否出现
部分操作依赖对应插件是否安装（如 siyuan-blog、PicGo 插件）。
:::

## 发布源笔记本

这是文章管理里最需要理解的一项。

- **用途**：笔记多时，避免列出所有笔记本的全部文档；同时限制**只能发布**选中笔记本内的文档，把公开内容与非公开内容隔开。
- **两层作用**：既过滤列表，也在发布时做校验。
- **配置位置**：设置 → 偏好设置 → 发布源笔记本。
- **留空语义**：不限制。

::: warning 越权会被拦截
配置了发布源笔记本后，发布不在范围内的文档会被拦下并给出明确提示。挂件模式同样适用这套规则。
:::
