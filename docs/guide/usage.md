# 使用指南

发布工具把「写」和「发」分开：文档照常在思源里写，发布配置与发布状态都收在插件的面板里。

## 三种发布方式

按使用频率排序，先看第一种就能用起来。

| 方式 | 适合场景 | 文档 |
|---|---|---|
| **快速发布** | 选个平台就发，接受默认参数 | [快速发布](/guide/quick-publish) |
| **详细发布** | 需要调标题、摘要、标签、分类、别名等 | [详细发布](/guide/single-publish) |
| **批量分发** | 同一篇文档一次发到多个平台 | [批量分发](/guide/batch-publish) |

| 功能 | 说明 | 文档 |
|---|---|---|
| 文章管理 | 集中列出与操作已发布、未发布文档；可按发布源笔记本隔离范围 | [文章管理](/guide/article-manage) |
| 发布设置 | 平台账号、图床、偏好与 AI 设置 | [发布设置](/guide/settings) |

## 快速开始

1. **安装并启用插件**：在思源插件市场安装「发布工具」。
2. **配好第一个平台**：打开面板 → 设置 → 账号设置 → 添加账号，填完字段后点「验证」，状态显示「运行中」即可。
3. **发布第一篇**：回到快速发布，选刚配好的平台，点「发布」。

::: tip 需要精细控制时
在快速发布的卡片上点「详细发布」，可以逐项调整标题、摘要、标签、分类与别名。
:::

## 界面说明

插件以原生面板挂在思源内，跟随思源的深浅色主题。同一套界面同时用于插件本体与四个 web 产物（挂件、浏览器扩展、nginx、vercel）。
