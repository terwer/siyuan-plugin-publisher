# CORS 代理配置

部分平台（如 Telegraph、部分网页授权平台）在浏览器环境下受同源策略限制，需要经过一个跨域代理才能访问。插件本身**不提供公共代理地址**——公共额度容易被滥用，因此需要你自己准备。

## 什么时候需要

| 场景 | 是否需要自备代理 |
|---|---|
| 思源桌面端（Electron） | 多数平台走宿主网络栈，通常不需要 |
| 浏览器扩展 / 挂件 / 网页版 | 受同源策略限制的平台需要 |
| 平台明确提示「需要配置 CORS 代理地址」 | 需要 |

## 配置位置

设置 → 账号设置 → 对应平台的配置页 → **跨域代理地址**（部分平台在偏好设置里）。

## 自建代理

最简单的方式是用 [cors-anywhere](https://github.com/Rob--W/cors-anywhere) 这类通用代理，部署到你自己的服务器上：

```bash
git clone https://github.com/Rob--W/cors-anywhere.git
cd cors-anywhere
npm install
npm start
```

启动后默认监听 `http://localhost:8080`，把该地址填进「跨域代理地址」即可。

::: warning 不要使用来源不明的公共代理
公共代理能看到你发出的全部请求内容，包括平台凭据。务必使用自己部署或可信来源的代理。
:::

## 常见问题

### 填了代理地址仍然失败

1. 确认代理服务本身可访问：在浏览器打开代理地址，应返回 cors-anywhere 的说明页。
2. 确认地址**带协议**（`https://` 或 `http://`）且**不含末尾斜杠**。
3. 如果代理部署在本机，注意思源 Docker 版中 `localhost` 指向容器自身，需要改用宿主机地址。

### 代理地址需要登录

部分代理服务（包括 cors-anywhere 默认配置）需要先访问一次授权页开通临时权限。按该服务的说明操作即可。
