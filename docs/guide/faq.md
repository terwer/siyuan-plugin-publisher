# 常见问题

这一页收集配置与发布过程中最常见的疑问。按主题分组，遇到问题先在这里找。

## 安装与更新

::: tip 建议先卸载再安装
本插件迭代频繁。为避免程序缓存导致不可预知的问题，更新时请**先卸载、再重新安装**，不要直接覆盖。
:::

### 配置异常导致插件完全不可用怎么办

备份 `[workspace]/data/storage/syp/sy-p-plus-cfg.json`，然后删除它——这个文件会在首次使用时自动重新初始化。

操作时最好**先关闭思源**，删除配置后再打开，防止思源运行中已读取旧数据又把配置覆盖回去。

::: warning
插件能正常使用时**不要**做这个操作。
:::

## 平台配置

### GitHub / GitLab 系平台有什么特别要求

只支持**源码部署**。请确认你的仓库里存的是可构建的源码目录结构，而不是已构建的产物。

### 知乎和 CSDN 应该选哪种发布格式

这两个平台目前**只能选择 HTML 模式**发布。在平台配置里把「发布格式」设为 HTML 即可正常使用。

### 知乎的专栏怎么获取

1. 打开知乎个人主页，找到你的用户名。
2. 在插件配置页的「用户名」字段填入它。
3. 点「验证」，通过后即可从专栏列表里选择。

### CSDN / 知乎过一段时间提示「需要登录」

这通常是 Cookie 过期。以 CSDN 为例：

1. 安装「网页视图」插件，在思源内打开 CSDN 首页并**退出登录**。
2. 回到插件配置页，重新授权。

::: tip
必须在思源的网页视图里退出登录才有效，在外部浏览器退出不会同步。
:::

### 知乎授权报 `{"code":40362}` 或提示请求异常

知乎已限制在 Electron 内登录，因此**只能复制 Cookie**。请升级到最新版插件，删除该平台账号后重新导入。

### CORS 代理怎么配置

见插件内的「CORS 代理配置指南」。如果平台配置异常，先确认思源地址与端口填写正确（默认 `127.0.0.1`，本地使用）。

### Docker 版初次打开显示不正常

检查「偏好设置」里的思源地址是否包含端口。Docker 环境下填错地址会导致读不到数据。

## 发布行为

::: warning 每次发布都会覆盖正文
发布工具每次都会获取思源中**最新编辑的正文**进行覆盖发布。因此**不要在平台上直接修改正文**，改动会在下次发布时被覆盖。
:::

### 各平台的图片是怎么处理的

| 平台类型 | 图片处理方式 |
|---|---|
| 知乎、CSDN、微信公众号 | 使用平台自带上传 |
| Notion、语雀、掘金 | 需要配置图床（平台原生直传或自备图床） |
| GitHub 系、GitLab 系（Hexo 等） | 需要配置图床 |
| MetaWeblog 系（博客园、Typecho、WordPress） | 图床与平台自带都支持；配了图床优先用图床 |

::: tip 想强制用平台自带上传
卸载图床插件即可。知乎这类平台不支持外链，只能用它自己的上传。
:::

### 掘金发布时提示缺少分类或标签

掘金平台强制要求标签与分类。未显式设置时，插件会回退默认分类「后端」与默认标签「程序员」。

### 掘金发布后马上预览是 404

掘金每篇文章都要审核。审核通过前可把链接里的 `/post` 临时改成 `/spost` 查看，或等审核通过。

### CSDN 必须设置标签

这是 CSDN 平台规定，标签不能为空。

### 博客园外链 404 或 H1 标题被替换

- 外链 404：可通过调整博客园用户配置解决。
- H1 标题异常：多半是发布格式选错了。博客园请使用 **Markdown**，不要用 HTML。

### Notion 为什么不支持更新

Notion 基于块结构而非整篇文档。当前实现采用「先删除再发布」的方式支持更新，因此耗时可能比普通更新久一些。

### 微信公众号为什么不能直接登录

微信在 Electron 上有登录限制。请自行访问 `https://mp.weixin.qq.com/` 登录，然后复制 Cookie 粘贴到配置项。

## 菜单与入口

### 菜单开关怎么用

「顶栏菜单」开关实时生效；「文档菜单」需要重新加载插件或重开思源后生效。
