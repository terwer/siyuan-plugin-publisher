# 分类体系

平台对文章的归类方式分为**单选分类**与**多选分类**两类，配置账号时按平台能力选择。

## 单选分类

只能选一个分类/专栏/空间。常见于使用「知识空间 / 专栏」概念的平台，例如：

- 知乎（专栏）
- 哔哩哔哩（B 站，投稿分区）
- 语雀（知识库/知识空间）

## 多选分类

可选择多个分类/标签。常见于使用「分类目录 / 标签」体系的平台，例如：

- WordPress（分类目录，支持多选）
- 博客园（博客分类）
- 通用 MetaWeblog 类平台

## 说明

- 具体可用字段与取值因平台而异，以各平台配置页提示为准。
- 发布脚本（YAML/metadata）会按所选方式写入对应平台字段。
